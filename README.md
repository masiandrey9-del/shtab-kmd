# Штаб КМД

CRM для клиентов, объектов и маркетинга: задачи на сегодня и завтра, воронка с перетаскиванием, карточки клиентов, ролики и медиаплан.

- Сайт: статический, GitHub Pages (`index.html`, `app.js`, `style.css`).
- База: Supabase, таблица `docs` (`schema.sql`). Данные клиентов в репозитории не хранятся.
- `config.js`: адрес проекта Supabase и публичный ключ anon (без входа данные не читаются).
- `tools/crm.py`: доступ к базе по служебному ключу (для автоматических задач и Claude).
